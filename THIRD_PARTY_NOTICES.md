# Third-party / external components

This repository's original code is designed to interoperate with, but does not vendor, the following software and project assets:

- MuJoCo — physics simulation engine;
- Gymnasium — environment API;
- Stable-Baselines3 — SAC implementation and vectorized environment utilities;
- PyTorch — neural-network backend;
- Fizzy research/summer-school environment and robot model — supplied separately by RWTH Aachen / IRT and collaborators.

Scientific context:

G. Spigler, S. Silenzi, B. Horstman, H. Vallery, “Intuitive Engineering as a Proxy Facilitates the Evolutionary Optimization of an Underactuated Robot Ball,” Workshop on Embodiment-Aware Robot Learning @ RSS 2024.
