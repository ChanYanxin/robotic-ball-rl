# Uploaded-material audit summary

## Directly useful for this portfolio

### `2026_materials.zip`
Main final practical package. It contains three Fizzy practical notebooks, a supplied MuJoCo/Gymnasium environment, pretrained SAC checkpoints, a VMC baseline, a real-robot UDP adapter, and lecture slides.

The saved Practical 2 notebook contains the completed tangential reward implementation, a 100,000-transition SAC run with 16 environments, and a deterministic trajectory/radius evaluation figure. The optional circle-reward section is still empty.

The saved Practical 3 notebook contains the hardware scaffold, but the student sensor-collection cell is empty and the transfer cell still has unconfigured scale values. This archive therefore does not verify successful real-robot deployment.

### `Programming Exercise.zip`
Useful for understanding how Fizzy simulation was introduced earlier in the week, but the package's README/model materials carry RWTH/IAT “All rights reserved” language. None of those source files are copied into the public portfolio.

## Background material, not portfolio source

- `Preparation_summer_school.zip`: Python/Jupyter preparation.
- `Reinforcement_learning.zip` and `additional_RL_task.zip`: general RL exercises.
- `exercise.zip`, `solution.zip`, `ml_exercises_companion_slides.pdf`, `Slides_Notebook.zip`, `Slides_Smartphone.zip`: ML fundamentals / course-study material.

These are useful learning context but would dilute the GitHub story, so they are not included in the project repository.
